# HelixServe Testing Pack

This folder organizes the STLC assets for HelixServe, a lightweight LLM serving runtime with paged KV allocation, prefix caching, scheduler queues, FastAPI endpoints, and CUDA/Triton optional paths.

Use it as the index for test planning, execution, and debugging:

- `stlc-plan.md` defines the lifecycle from requirement review through closure.
- `test-matrix.md` maps runtime features to positive, negative, and regression tests.
- `traceability.md` connects user-visible behavior to code and tests.
- `debugging-playbook.md` captures fast failure isolation steps.
